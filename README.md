# Sora Repository

Официальный репозиторий пакетов и рецептов для изолированного пакетного менеджера **Sora**.

## Структура

- `index.toml` — общий индекс доступных пакетов и версий.
- `packages/<name>/Recipe.toml` — рецепты установки и правила изоляции песочницы для каждого пакета.

## Использование с Sora

```bash
# Обновление индекса
sora update

# Поиск пакета
sora search telegram

# Установка пакета в изолированную песочницу
sora install telegram

# Удаление пакета
sora rm telegram
```
